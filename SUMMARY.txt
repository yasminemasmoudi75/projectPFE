🚀 FLUX IMPLÉMENTÉ
════════════════════════════════════════════════════════════════════════════════

  1️⃣ PAIEMENT ENREGISTRÉ
     └─ POST /api/reglements
        └─ Montant: 5000 DT
        └─ Commercial: CLI1557931125

  2️⃣ DÉTECTE COMMERCIAL
     └─ Récupère ID du commercial responsable
     └─ Recherche OBJECTIF ACTIF

  3️⃣ VÉRIFIE OBJECTIF ACTIF
     ├─ Objectif existe?
     ├─ Statut = "ACTIF"?
     └─ DateFin > Aujourd'hui?
        └─ Si NON → ARCHIVE AUTO

  4️⃣ AJOUTE LE MONTANT
     ├─ MontantRealise += 5000
     ├─ NombreReglementsLies += 1
     └─ Crée lien Paiement ↔ Objectif

  5️⃣ VÉRIFIE ARCHIVAGE
     ├─ Condition 1: MontantRealise >= MontantCible?
     ├─ Condition 2: DateFin < Aujourd'hui?
     └─ Si une condition vraie:
        ├─ StatutObjectif = "ARCHIVÉ"
        ├─ DateArchivage = NOW
        └─ Message: "OBJECTIF ARCHIVÉ (montant/date)"

  6️⃣ TRANSACTION COMPLÈTE
     └─ Tout enregistré en BD ou rien
